# Git 使用说明

此文档用于说明项目中 Git 的使用方法和规范。

---

## 1. 安装与配置 Git

### 1.1 准备工作

1. **Watt Toolkit**：安装 Watt Toolkit 用于加速 Github。
    - [Watt Toolkit 下载链接](https://steampp.net/download)
2. **VSCode**：安装 VSCode 用于代码编辑与可视化提交。
    - [VSCode 下载链接](https://code.visualstudio.com/)
3. **Godot**：下载 Godot 引擎，项目使用 GDScript 语言，请下载**普通版本**而非 .NET 版本。
    - [Godot 下载链接](https://godotengine.org/download)
4. **Git**：安装 Git 用于版本控制。
    - [Git 下载链接](https://git-scm.com/downloads)
    - 注：若看不懂安装程序，只需要点下一步即可。
5. **Github**：注册 Github 账号。
    - [Github 链接](https://github.com)
    - 如无法访问，请先打开 Watt Toolkit 加速 GitHub。

### 1.2 配置 Git 环境

1. 在开始菜单中打开 **Git Bash**。
2. 输入以下命令配置 Git 用户信息（每行输入后回车确认）：
    ```bash
    git config --global user.name "你的姓名"
    git config --global user.email "你的邮箱"
    ```
    示例：
    ```bash
    git config --global user.name "张三"
    git config --global user.email "1729000000@qq.com"
    ```

### 1.3 克隆项目仓库

1. 打开 VSCode。
2. 点击欢迎页面的 “**克隆 Git 仓库**” 按钮。
3. 登录 Github 账号。
4. 选择"从 GitHub 克隆"，并输入仓库地址 https://github.com/fepeng114514/FreeRadical.git。
5. 选择克隆到的本地目录即可。

> **注意**：若无法访问服务端，请先打开 Watt Toolkit 加速 Github。

---

## 2. 使用 Git 提交代码到仓库

### 2.1 打开项目并修改代码

修改前必须先拉取最新代码，避免冲突。

1. 首先打开 VSCode。
2. 点击打开文件夹，选择项目目录。
3. 点击左侧 “源代码管理” 选项。
4. 点击图形栏的 “拉取” 按钮，拉取最新代码。
5. 打开 Godot，选择项目目录。
6. 最后修改代码即可。

### 2.2 提交代码到仓库

1. 首先点击 “源代码管理” 选项。
2. 输入提交信息。
    - 提交规范见下方。
3. 点击 “提交” 按钮。
4. 暂存所有修改。
5. 最后点击 “同步更改” 按钮推送代码到仓库。

> **注意**：若无法访问服务端，请先打开 Watt Toolkit 加速 Github。

#### 2.2.1 解决冲突

提交时若出现冲突，需要先解决冲突，再推送代码到仓库。

1. 点击提示冲突的文件。
2. 根据差异提示，选择解决方式：
   - **应用本地修改**：保留你自己的改动。
   - **应用远程修改**：保留别人的改动。
   - **合并修改**：手动选择保留哪些内容。

**示例**：

> 你修改了哥布林的血量为 100，但别人将血量改为了 150 并新增了物理护甲 10。提交时会提示冲突。

三种解决方式的结果：

| 方式 | 血量 | 物理护甲 |
|------|------|----------|
| 应用本地修改 | 100 | 无 |
| 应用远程修改 | 150 | 10 |
| 合并修改 | 自行选择 | 10 |

### 2.3 提交规范

本项目使用**约定式提交规范**。核心格式如下：

```
<类型>[可选范围]: <描述>

[可选的正文]
```

#### 规范
1. 末尾增加句号。
2. 英文与中文之间用空格隔开。

#### 常用类型

| 类型 | 说明 |
|------|------|
| `feat` | 新增功能 |
| `fix` | 修复 Bug |
| `docs` | 仅文档变更 |
| `style` | 代码格式调整（空格、缩进等，不影响逻辑） |
| `refactor` | 代码重构（不修 Bug 也不加功能） |
| `perf` | 性能优化 |
| `test` | 添加或修正测试 |
| `chore` | 构建流程、工具等变动 |
| `ci` | CI 配置或脚本修改 |
| `build` | 影响构建系统或外部依赖 |
| `revert` | 回滚到之前的版本 |
| `balance` | 游戏平衡性调整 |
| `visual` | 视觉表现调整 |

#### 示例

```
feat(登录): 增加手机号验证码登录方式。

- 新增验证码发送接口。
- 增加登录校验逻辑。
```

```
fix: 修复用户未登录时页面白屏的问题。
```
