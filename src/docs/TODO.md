# 待办事项

本文档列出了项目开发过程中需要完成的待办事项。

---

## 1. bug 修复

1. 修复 AudioManager 只能同时播放一个音效的问题。
2. 修复有些地方没有连接资源变化信号，导致无法实时更新编辑器的问题。
3. 修复近战组件被拦截者被更改阵营后不会解除拦截的问题。
4. 让光环组件支持更改阵营。
5. 修复防御塔射手可以攻击当前防御塔被禁止的实体。
6. 修复兵营行为设置集结点位置滞后的问题。

1. 缓存搜索器结果，每两帧更新一次，使用搜索到的目标时需要检查是否有效性。

3. 将血条纹理放到图集中，以减少绘制调用。

## 4. 优化代码格式
