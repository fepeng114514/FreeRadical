#### 提交规范
本项目使用约定式提交规范。核心格式如下：

```
<类型>[可选范围]: <描述>

[可选的正文]
```

##### 规范
1. 使用中文编写提交信息。
2. 忽略所有 .import 文件的提交。
3. 末尾增加句号。
4. 所有英文与中文之间用空格隔开。

##### 常用类型
1. **feat**: 新增功能。
2. **fix**: 修复 Bug。
3. **docs**: 仅文档变更。
4. **style**: 代码格式（不影响逻辑，如空格、缩进）。
5. **refactor**: 代码重构（不修 Bug 也不加功能）。
6. **perf**: 性能优化。
7. **test**: 添加或修正测试。
8. **chore**: 构建流程、工具等变动。
9. **ci**:  CI 配置或脚本修改。
10. **build**: 影响构建系统或外部依赖。
11. **revert**: 回滚到之前的版本。
12. **balance**: 游戏平衡性调整。

##### 示例
###### 示例 1：
feat(登录): 增加手机号验证码登录方式。

- 新增验证码发送接口。
- 增加登录校验逻辑。

###### 示例 2：
fix: 修复用户未登录时页面白屏的问题。
